从紧到松：残响 17.4 > 渊盐 16.1 > 金币 15.9。三条线相差不到 1.5 局，属于「基本齐平、残响略紧」。

1.5 份余量是怎么来的

周期 = 27 枚残响 ÷ 1.55 枚/局 = 17.42 → 17.4 局
  • 17.4 不是拍的，是残响供给算出来的；所以残响是唯一瓶颈，金币不是。
  • 金币池只要 15.90 份，17.4 − 15.90 = 1.5，这 1.5 份就是金币线的余量。
  • 余量用来「防反超」：补给从金币里扣，扣太多金币会先见底。1 − s ≥ 15.90 ÷ 17.4 = 0.914 → s ≤ 0.086 份/局，取 8%，留 0.6% 缓冲。
  • 反解校验：15.90 ÷ (1 − 0.086) = 17.4，刚好追平残响；一旦超过 0.086，周期被拉到 31.8 局，金币变成唯一瓶颈。
  • 每局买顶档深海整备（38 币）后，金币线降到 15.1 份，与残响差 2.3 局，余量反而变宽。
三个历史数字不能混用：8,400 币与16.8 局已作废；966 只是满仓上限锚；3,660 币是现行代码全满价（7.77 份），不是总池。总池只有 15.90 份。

两种宝物，两条去向

藏品 · 14 件

开柜时走「藏品附加位」，拾取后不进货舱。撤离或击败 Boss 才登记；死亡 / 超时丢失。

去向：登记簿 → 陈列柜

货值件 · 3 档

进的是货舱，占的是货舱格。撤离结算时按件折币；死亡只返还 20%，超时返还 10%。

去向：货舱 → 卖成海币
  • 藏品不占货舱：柜内按 1×1 显示，拾取后直接进本局藏品列表，不会触发满舱或替换。
  • 孤品藏品 ≤ 1 件/局，其中圣物 ≤ 1 件/局；触顶后降档为少见。
  • 货值件一律不能进展厅；2×3 稀有件带出时会额外登记一枚海图碎片，但货本身仍然只能卖。
  • 展厅溢出走「暂存」：登记照常，等本体升级后按首次获得顺序自动补位。

展厅与收藏馆

展厅不是「买展位」，是「把空位填满」；本体只决定上限，不单独卖钱。空位不产生游客。

四条公式

游客 = min( round(S × 3 × r̄ × q), 展位上限 × 6 )　　q = 1 + 0.25 × (Lv − 1)
门票 = 游客 × 1 币　　　捐赠 = 少见件数 × 1 + 孤品件数 × 4
日净额 = clamp(门票 + 捐赠 − S × 2, 0, 40)　　离线 = min(floor(日净额 × 0.5), 25)，最多 12h
  • S = 占用展位数（藏品数与上限取小）；r̄ = 已展出藏品的加权平均稀有度。
  • 封顶项 上限 × 6 的作用：只升本体、不填展位，拿不到收益。
  • 捐赠只算已展出的藏品；库房里的不计客流、不产生捐赠，也不收维护费。
  • 按天结算、不按局：同一天连打十局不会多结；离线额度要手动「收账」。

哪些货不值得陈列

方案判定结果
A 按稀有度少见 / 孤品货可陈列破红线：0.32–1.26 份/件的卖价损失，约 4 局一件就吃光余量
B 按单件价阈值≥ X 币可陈列同样破红线；阈值越高越等于只放孤品，仍是 1.26 份/件
C 按品类（采用）id ∈ loot.collectibles（14 件）金币损失 = 0：藏品本无卖价，周期与瓶颈不动
  • 判定一句话：能陈列的是「品类」，不是「价值」。货值件徽标「不值得陈列 · 建议卖掉」；藏品徽标「可陈列」。
  • 失败结局（沉没 / 弃船 / 风暴）只允许卖出，否则可以故意沉船保货，绕过 20% / 10% 的惩罚。
  • 展厅满不拒绝、不顶替：走「暂存（登记但不展出）」，本体升级后按首次获得顺序自动补位。
  • 圣物可陈列，但不计游客、不参与消耗，所以它不推动上面任何一条收益公式。

为什么推荐 B1

  • 包体唯一可行：+0.8–1.0MB；B2 与 C 都会把余量吃光（20MB 红线）。若实测余量只有 0.3–1MB，先做 PNG 量化 / 释放休眠 UI。
  • 产能可持续：第三章边际 ≈1 配置日 + 1 Boss 代码日 + 3–5 美术日，能按「一章一皮肤包」排期；C 每章 12–18 日不可持续。
  • 判据能过：怪权重 ≥30% 重排 + 货值表重定价两项，满足换皮判据的「至少两项」；节奏不同是硬条件。前提是先修订局外 spec 的「零贴图」硬约束。
  • 骨架可复用：第二章曲线（165s / 9,000 血 / 精英 ×1.2 / 密度 ×1.12）已实测 74%，不需要重做数值，只补主题层。
  • 风险可控：环境机制可按开关灰度；不改地图尺寸与撤离点唯一性，验收线漂移面最小。

现状提醒：现在的第二关其实已经是 A 的雏形——同图、同 tide_lord、同美术，只换曲线与 9,000 血，玩家感知接近 0。这正是「只换数值」这条路的实测答案。
